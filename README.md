# Дорога.МСК

Мобильный веб‑сервис: сфотографировал проблемное место на дороге → геолокация → короткое описание → точка на карте России. По скоплениям видно, где проблема повторяется чаще всего.

**Карта:** тайлы **2ГИС** (без API‑ключа, стабильно из РФ)  
**Поиск адресов:** Photon / OpenStreetMap (Россия)

## Запуск у себя на компе

Нужны Node.js 20+ и npm.

```bash
git clone <url-репозитория>
cd <папка-проекта>
npm install
npm run dev
```
## Стек
Next.js, TypeScript, Tailwind, shadcn/ui, Leaflet, 2ГИС tiles, MarkerCluster.
